# python-snowtrace

**Archived project.** This repository contains a historical Python client for [Snowtrace.io](https://snowtrace.io/). Current API availability and package compatibility have not been verified.

The [original documentation](https://github.com/EmperorMew/python-snowtrace/blob/8fc1c78ab9120590fa8430ae630192d64945d8a2/README.md) remains available for reference. The package's [PyPI listing](https://pypi.org/project/python-snowtrace/) records its last release as version 1.1 in August 2022.

The original documentation credited [Snowcones.io](https://www.snowcones.io/) and the [Snowtrace.io APIs](https://snowtrace.io/). The source is under the [MIT license](LICENSE).
